# Phase 3: 2025年の実上映データ

2026年の上映情報未公開のため、ユーザー指定により2025年10月27日〜11月5日を対象とする。
公式サイトが配信する公開データから149作品・282上映・13会場を収録した。映画祭の全企画を網羅するデータではない。

## 取得と再生成

主出典は公式ページの `js/getdata/main.build.js` が利用する公開エンドポイント:

- https://api-2025.tiff-jp.net/api/venues/acts
- https://2025.tiff-jp.net/ja/schedule/list/
- 照合用PDF: https://2025.tiff-jp.net/download/TIFF2025_GUIDE_Schedule-ja.pdf
- PDF掲載後の追加情報: https://2025.tiff-jp.net/news/ja/?p=66803

確認日時は `data-sources/tiff-2025.json` の `retrievedAt` に保持する。
元レスポンスのうちID・作品名・本編分数・上映日・開始終了・会場・イベント種別のみを選別して保存した。
画像、作品紹介、ゲスト情報、HTMLは転載しない。公式資料の権利を本リポジトリのコードライセンスで再許諾するものではない。

取得時に利用規約 https://2025.tiff-jp.net/ja/general/termofuse.html と robots.txt を確認。
robots.txtはGooglebot用の空Disallowと2020年のsitemapを返した。これは再配布許諾を意味しない。
自動クロール・定期取得・ブラウザから公式へのAPI通信は実装しない。取得した事実情報を出典付きで正規化する。

```sh
# 保存済みの事実データから決定的に再生成（ネットワーク不要）
npm run data:import
# コミット済みJSONと再生成結果の一致・参照整合性などを検証
npm run data:check
# 手動で取得した公式レスポンスを正規化して更新
npm run data:import -- /path/to/official-venues-acts.json
```

`data:check` はbuildに含まれるため、既存のCIでも実行する。未知会場・重複ID・矛盾する作品情報は失敗させる。
本編時間不明・複数作品の上映時間表記・受賞作品未確定の枠、および業界向けイベントを除外した。
除外35件は `data-sources/import-report-2025.json` に理由付きで残し、画面に件数を表示する。
学生映画コンファレンス、PFF複数作品枠などを根拠なく単一作品にまとめたり、時間0分で投入したりしない。
11/8〜9のMISHIMA特別追加上映は対象期間外。

## 時刻の意味

- `startAt`: 公式 `play_at`（開場時刻 `open_at` ではない）。舞台挨拶が先ならイベント開始時刻。
- `endAt`: 公式 `end_at` と「開始＋本編分数」の遅い方。これは本編だけの終了ではなく、上映・イベントの確保枠の終了。
- `Film.durationMinutes`: 公式 `film_time_length` の本編分数。
- イベントの前後の内訳は不明なので、推測で `eventBeforeMinutes` / `eventAfterMinutes` を追加しない。公式枠に含まれる余裕を二重加算しない。
- `eventLabel` は公式フラグ、`timingNote` は終了の意味または補正理由。UIとタイムラインに表示する。
- 入退場バッファはこの枠の外側に別途加算する。
- 全日時は `+09:00`。日跨ぎ枠は現コアの対象外。

公式終了が本編時間より短い6件（キカ2件、蜘蛛女のキス2件、マン・オブ・スティール1件、春の木1件）は本編時間以上になるよう補正。
公式情報同士の不整合であり、確定した実際の終了時刻ではない。延長や当日の変更、チケット可否は保証しない。
公式の時刻説明: https://2025.tiff-jp.net/news/ja/?p=67116

## 移動時間

会場はスクリーン単位。日比谷12・13は東京ミッドタウン日比谷ではなく東京宝塚ビル地下として扱う。
所在地・駅からのアクセスの出典: https://2025.tiff-jp.net/ja/access/

`data-sources/travel-2025.json` に推定根拠を保持。最短経路の計測値ではなく、JR有楽町駅を経由する保守的な徒歩計画。
全会場の全方向を生成し、未定義経路へのフォールバックはしない。

| 建物・会場 | 有楽町駅までの徒歩（分） | 建物内移動（分） |
|---|---:|---:|
| TOHO日比谷12・13 | 5 | 2 |
| TOHOシャンテ | 5 | 2 |
| 日比谷ステップ広場 | 5 | 0 |
| 角川シネマ有楽町 | 2 | 4 |
| ヒューマントラスト有楽町 | 1 | 3 |
| 有楽町マリオン（ピカデリー・ヒューリック） | 3 | 5 |
| シネスイッチ銀座 | 10 | 2 |
| 国立映画アーカイブ | 18 | 3 |

駅徒歩は公式記載の値（ミッドタウン5分・ヒューマントラスト1分・ヒューリック3分・シネスイッチ10分）を参考にし、未記載会場は所在地から余裕を持って推定した。建物内移動はすべて本アプリの推定値。
異なる建物間は「両端の駅徒歩＋両端の建物内移動＋信号待ち2分」を5分単位で切り上げる。
同一建物の別スクリーンは5分、同一スクリーンは0分。入場10分・退場5分の既定バッファは別途。
この方針は近隣建物間で遠回りになることがあり、徒歩最短ルートに基づく最適解を保証するものではない。

## 祝日

開催期間中の2025-11-03（文化の日）を静的保持。2026年の祝日を流用しない。
出典: 国立天文台 https://eco.mtk.nao.ac.jp/koyomi/yoko/2025/rekiyou251.html

## UIと検証

2025年アーカイブであること、公式出典・確認日、除外数・補正数、終了枠・移動推定の意味を画面に明記。
149作品から探せるよう作品名検索（NFKC正規化）と選択中のみ表示を追加。検索によって選択は失われない。
サンプルデータは回帰テスト専用fixtureへ移動。

検証はコアの入力検証に加えて、期間・JST・本編より短くない枠・出典・会場×開始時刻重複・孤立作品・全移動経路・祝日をチェック。
公式PDFのMISHIMA上映、追加発表の蜘蛛女のキス・Dear Stranger、イベント二重加算防止、実データでの休暇最適化をテスト。

探索コアはPhase2と同じ同期DFS。大量作品の同時選択時の性能改善・WorkerはPhase5、GitHub Pages公開はPhase4。

## 作品選択の改善

149作品を12作品ずつ表示し、上映日時・会場は各作品の開閉式詳細に移動。
作品名（全角半角・英字大小・ひらがなカタカナを正規化）、部門、上映日、選択中のみを組み合わせて絞り込める。
検索・部門・上映日の変更時は先頭ページに戻り、ページ移動や絞り込みでは選択を保持する。
「選んだ作品を確認」は検索・部門・日付条件を解除して選択済み作品を表示する。
上映日フィルターは作品検索専用で、最適化対象の上映日を制限しない。

部門名は公式 https://api-2025.tiff-jp.net/api/departments のID・日本語名を
`data-sources/departments-2025.json` に取得日時付きで保存。
保存済み上映データの `departmentId` と対応させて `Film.department` を生成する。
未知の部門ID、同一作品で矛盾する部門は再生成時にエラーにする。
選択肢には収録作品のある部門・企画だけを件数付きで表示する。
