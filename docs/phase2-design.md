# Phase 2: Basic UI

## 範囲と構成

SPEC.md §19のPhase 2をReact + TypeScript + Viteで実装する。
既存のScheduler Coreは変更せず、Appから入力を渡し結果を表示する。

- `src/App.tsx`: 作品一覧・選択、条件設定、生成、最大3案の比較表示。
- `src/ui/timeline.ts`: 結果を日別の入場/前イベント、本編、後イベント/退場、移動、昼食へ変換。
- `src/ui/data.ts` / `src/data/*.json`: 差し替え可能なサンプル入力。
- `src/styles.css`: 2カラムの作業画面、狭い画面で1カラム、ラベルとフォーカス表示。

初期選択は空。選択がなければ生成できない。条件・選択の変更で結果とエラーを破棄する。
フォーム検証で必須時刻・分数の範囲を確認し、昼食時間帯の矛盾は日本語で説明する。
計算例外はエラーとして表示し、0作品の有効プランと区別する。

## 条件

勤務曜日、追加休日、休暇取得不可日、昼食時間帯/30・45・60分、入退場バッファを設定できる。
勤務時間はコアの初期値9:00〜18:00で固定し、画面に明示する。休暇不可日の勤務時間外は参加可能。
日付追加は重複排除し、個別削除可能。選択と条件はメモリ内だけで保持する。

## 結果

休暇日数・鑑賞日数・鑑賞作品数・移動分数・待ち分数を案ごとに表示する。
鑑賞できない作品は名前を表示し、条件の見直しを案内する。
全作品が入らない理由の詳細な競合説明はPhase 5に残す。
日付・時刻は端末のタイムゾーンによらず日本時間で表示する。

タイムラインはコアのoccupiedとtravelMinutesを利用し、移動は退場直後へ配置する。
上映前後イベントと入退場をまとめた区間として表示し、映画本編と区別する。
昼食はコアが返した区間をそのまま描画する。0分区間は省略する。

## データ・境界

6作品・12上映・2会場、2026-10-30〜31の**架空データ**。
15分の会場間移動も仮値。祝日は空配列。画面で常時明示し、実際のTIFF予定に使わないよう案内する。
実データ/祝日/現実の移動マトリクスはPhase 3で整備する。
同期計算を利用するため、大量データのUI応答性は未保証。Web WorkerはPhase 5。
公開は行わず、Vite baseのみ仕様の `/TIFFScheduler/` に設定する。

## ビルド・検証

`npm run build` は型検査後にViteで静的アプリをdistへ出力する。
既存コアのビルドは `npm run build:core` でlibへ分離し、アプリ配信物に混在させない。
既存CIのnpm ci / typecheck / test / buildがそのままUIも検査する。

- 既存12テストと、新規3テスト（サンプル全作品成立、日別タイムラインの非重複と移動/昼食整合性、休暇不可の代替案、日本時間表示、空タイムライン）。
- strict型検査、アプリ本番ビルド、コア単体ビルド。
- 実ブラウザ/iPhone Safariの操作確認は未実施。Phase 4のモバイル検証で確認する。
