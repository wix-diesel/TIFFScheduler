# Issue #9: 1日最大鑑賞本数

## 仕様

`UserConstraints.maxScreeningsPerDay` は全日共通の任意制約とする。未指定は制限なし、指定時は1以上の安全な整数だけを受け入れる。選択作品数より大きな値も有効である。

上映枠は上映開始時刻を日本時間へ変換した日付ごとに数える。作品の長さ、終了日、イベントや入退場バッファによる占有日のずれには影響されず、短編集も上映枠単位で1本とする。

## 探索

`withinDailyScreeningLimit` が選択済み上映を日付別に集計する。DFSで候補を追加するたびに判定し、上限超過時点で枝刈りする。上映を後から追加して超過が解消することはないため、この枝刈りは最適解を失わない。

未鑑賞分岐は従来どおり残す。したがって全作品を上限内で鑑賞できなくても、スコア順（最大鑑賞数、休暇、移動、待ち時間）による最大3件の代替案を返す。未指定時は判定が常に成功し、従来の探索順と決定性を維持する。

## UI・保存・互換性

条件欄の数値入力は空欄を制限なしとして扱う。値は既存の自動保存対象であり、現在条件と名前付きプランのスナップショットへ保存する。任意項目の追加なのでschemaVersionは1を維持し、既存データに項目がなければ制限なしへ移行する。

## 検証

- 同日3本に上限2本を適用した代替案
- 別日候補への振り分け
- UTC表記を含む日本時間の日付境界
- 未指定および選択数より大きな上限
- 0、負数、小数、非有限数の拒否
- 日次上限を含む小規模総当たりとBranch and Boundの上位3案一致
- ブラウザ入力の自動保存・復元
