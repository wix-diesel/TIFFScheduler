# 2026年の上映データ

対象期間は第39回東京国際映画祭の2026年10月26日〜11月4日。
2026年10月1日に公式公開データを取得し、134作品・247上映・12スクリーンを収録した。

## 出典と更新

- 指定された公式ガイドPDF（20〜23ページ）：https://2026.tiff-jp.net/download/39th_TIFF-Guide-high.pdf
- 最新の公式上映データ：https://api-2026.tiff-jp.net/api/venues/acts
- 部門名：https://api-2026.tiff-jp.net/api/departments
- 会場所在地・アクセス：https://2026.tiff-jp.net/ja/access/

PDFの開催期間と、我々は宇宙人・聴覚・夜明け前の赤・ゴジラ-0.0・コロニー／群体などの上映日、開始時刻、スクリーンを照合した。
PDFに未掲載のワイルドウッド・DAUなどの上映も公式公開データから取り込む。
PDFと公式公開データで本編分数が異なる場合は、取得時点の公式公開データを採用する。
終了時刻はPDFの開始＋本編分数から推測せず、公式の上映枠終了と開始＋最新本編分数の遅い方を使う。
舞台挨拶等は公式枠に含まれ、追加のイベント時間を二重加算しない。

取得日時は `data-sources/tiff-2026.json` と `departments-2026.json` に保持する。
保存するのは事実情報のみ。PDF、画像、作品紹介文、ゲスト情報、HTMLはコミットしない。

```sh
npm run data:import
npm run data:check
npm run data:import -- /path/to/official-venues-acts-2026.json
```

通常のビルド・検証では公式サイトに通信せず、保存済み出典から再生成する。
旧年度の `data-sources/*-2025.json` はアーカイブと回帰検証用に保持する。
2026年の部門ID・会場IDは2025年と異なるため、年度ごとの対応表を使用する。

## 収録範囲と時刻補正

公式261枠のうち14件を除外した。詳細は `data-sources/import-report-2026.json` に残す。
本編時間未記載、複数作品の分数表記、受賞作品未確定、業界向けイベントが対象。
業界向けイベント部門のMPA特別企画上映も既存の収録方針に従って対象外にする。
除外された枠を時間0分の作品として登録しない。

終了時刻が本編分数より短い9件は、本編終了まで枠を延長し補正表示を付ける。
対象はときに悲しみ、ときに反逆（3件）、地獄が来たとしても（1件）、瞬く光の陰で（1件）、ワイルドウッド（2件）、DAU（2件）。
公式データの不整合に対する補正であり、当日の変更や延長、チケット取得可否は反映しない。

移動時間は2026年の会場所在地を確認し、既存のJR有楽町駅経由の保守的な徒歩推定を継続する。
同一建物別スクリーンは5分、同一スクリーンは0分。入退場バッファは別途確保する。
開催期間中の祝日として2026-11-03（文化の日）を収録する。

画面の年度、開催期間、出典リンク、件数を更新した。
ブラウザ保存は既存の年度別キーを使用するため、2025年の作品選択・保存プランを2026年に混在させない。
2025年の保存内容は旧キーに残り、削除・上書きしない。
